## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/TaylorOkis/Login-page.git
```

Navigate into the project:

```bash
cd Login-page
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```
